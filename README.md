📖 Overview

This repository contains my C++ programming work completed as part of my academic coursework at Superior University.

It is organized into two main areas:

Programming Fundamentals: A collection of programming exercises and practical management-system projects focused on developing core programming skills and logical problem-solving abilities.
Object-Oriented Programming (OOP): Academic assignments that explore object-oriented design and concepts such as classes, objects, encapsulation, and inheritance.

The projects range from introductory exercises involving arrays, C-strings, functions, and mathematical computations to larger console-based applications that simulate real-world billing, shopping, restaurant, utility, and record-management systems.

The purpose of this repository is to document my learning journey, strengthen my C++ programming skills, and demonstrate the practical application of programming concepts.

🚀 Compiling and Running C++ Programs

You can compile and run individual C++ programs using the GCC compiler.

Compile
g++ program_name.cpp -o program_name

Run on Windows PowerShell
.\program_name.exe

Run on Linux or macOS
./program_name


Replace program_name.cpp with the name of the source file you want to execute.
